# Calculator in C

A menu-driven calculator made in C for my BCA 1st semester.

## Features
- Addition, Subtraction, Multiplication, Division
- Modulus, Power, Square Root
- Factorial (0 to 20), Percentage
- History of last 10 calculations
- Handles wrong input (like typing letters), divide by zero and negative square root

## How to run
```
gcc calculator.c -o calculator -lm
./calculator
```
On Windows: `gcc calculator.c -o calculator.exe -lm` and then `calculator.exe`

## What I learned
- functions and switch-case
- while loop and arrays
- strings (sprintf, strcpy) for saving history
- checking scanf return value for input validation
- math.h functions (pow, sqrt, fmod)
